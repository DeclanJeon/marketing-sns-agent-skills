# 입력 부족·제약 대응

| 상황 | 진행 가능한 작업 | 보류 조건과 요청 |
|---|---|---|
| 영상/URL 접근 불가 | 실제 제공된 설명만 user_reported로 초안 작성 | 보지 않은 장면·대사·수치를 만들지 말고 자막/파일 요청 |
| 구매·체험 링크 없음 | 댓글 질문 또는 관심 조사 CTA | 즉시 구매/다운로드 약속 제외; 실제 공개 가능 경로 필요 |
| 성능·효능 근거 없음 | 작업 과정·구현 범위·검증 계획 | 속도/정확도/우월성 문구 삭제 또는 근거 요청 |
| 미디어 제작 도구 없음 | 완성 대본·카드 문구·제작 명세 | 프롬프트를 미디어 파일로 간주하지 않음 |
| 시간·예산 부족 | 요청 채널의 최소 초안 모두 제공, 운영 우선 채널 1~2개 제안 | 제작·QA·댓글·측정 시간을 합산; 초과 일정은 축소 |
| 브랜드/대상 미정 | 명시적 가설로 최소 타깃·톤 결정 | 중요한 브랜드 요구가 충돌할 때만 질문 |
| 계정 권한·기능 미확인 | 수동 게시 패키지 | 실제 게시·ready 판정은 검사/권한 충족 후 |
| 성과 없음/분모 0 | 측정 계획/계산 불가 표시 | 성공·우승·매출 추론 제외 |
| 실행 응답 유실 | unknown 이벤트와 결과 조회 작업 | 결과 조회 전 재실행 금지 |

모든 미해결 항목에 영향 게시물, severity, next_owner, 요청 자료와 재개 조건을 남겨라. 한 채널 blocker로 전체 캠페인의 유효 초안을 폐기하지 말라. 단계가 보류되어도 실제 제공 가능한 산출물은 완성해 반환하라.
