# 실행과 수락 기준

예시 요청: 광고·메시지 설계을 적용해 2인용 일본 골프투어 상품을 기획하고 판매를 늘릴 실행안을 만들어라. 공급 원가·휴일 추가금·취소 조건은 제공 자료만 사용한다.

수락 조건: 위 산출물을 실제 고객·상품 자료로 채워라. 숫자·정책이 없으면 명시적으로 확인 필요를 표시하라. “예약 30% 증가” 같은 결과를 보장하지 말라. 제안 가격과 승인 가격을 구분하라. SNS 초안을 요청받았다면 완성 원고를 제공하고, 게시까지 요청받았다면 승인 범위와 연결 상태를 확인해 실행 결과를 기록하라.

실패 예: 근거 없는 시장 규모; 가격과 추가금 누락; 템플릿만 반환; 고객 질문 없이 B2B 압박 대본 사용; 모델 확률만으로 외부 행동을 승인함.
