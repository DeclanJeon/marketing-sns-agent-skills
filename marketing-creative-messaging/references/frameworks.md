# 아이디어와 메시지 제작

B01의 5단계: 구체·일반 자료 수집 → 관계 탐색과 재조합 → 의도적 작업 전환 → 발견한 아이디어 기록 → 현실 검증과 개선. 에이전트는 인간처럼 무의식 숙성을 경험했다고 주장하지 말고 다른 관점 생성 후 재검토로 구현한다.

B11의 SUCCESs를 검수 질문으로 사용한다: Simple(핵심); Unexpected(관련 있는 정보 공백); Concrete(관찰 가능한 장면); Credible(근거); Emotional(고객에게 중요한 의미); Stories(문제·행동·결과). 여섯 요소를 모두 억지로 넣기보다 목표 행동과 매체에 필요한 요소를 선택한다.

B16의 광고 검수: 조사된 고객 이익 → 주요 약속 → 헤드라인 → 시각과 설명 → 근거 → 다음 행동. 제품 사실과 일반 문화 자료를 구분한다. 창의성 선호가 매출 증거가 아니므로 주목·이해·전환을 분리한다.
