# 공식 안내 확인 메모

조회일: 2026-10-02. 전략적 권장사항은 실험 가설이며 공식 알고리즘의 보장이 아니다. 신규 캠페인 또는 실제 게시 전 재확인하라.

- https://support.google.com/youtube/answer/15424877?hl=en
  - 현재 조회한 영문 안내: 정사각형/세로, 최대 3분 Shorts. Content ID 조건은 언어별 검색 결과에서 상충하므로 출시 시점·지역별 최신 안내를 확인하라. 이 패키지는 음원 사용 가능을 판정하지 않는다.

- https://support.google.com/youtube/answer/10059070?hl=en-GB
  - Shorts views는 재생/재재생 시작 수이며 engaged views는 계속 보기 지표로 별도 유지된다.

- https://support.google.com/youtube/answer/13748639?hl=en
  - Shorts 설명/댓글 일반 URL은 클릭되지 않는다. 채널 프로필/관련 영상 등 경로를 사용하고 외부 링크 권한을 확인하라.

확인 기록 형식: rule_id, official_url, checked_at, account_scope, confirmed_rule, status(confirmed/unverified/conflicting), fallback. 규격의 확인 일자와 추천 실험의 근거를 구분하라.
