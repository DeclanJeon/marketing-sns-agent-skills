# 데이터·실험 프레임워크

## Factfulness의 10개 사고 점검을 마케팅 검수로 재구성 (B06)
- 간극: 두 극단 대신 분포·중간 고객을 확인.
- 부정: 나쁜 사례와 장기 추세를 함께 확인.
- 직선: 성장 외삽 전에 곡선·포화·기저를 확인.
- 공포: 노출과 실제 위험을 구분.
- 크기: 분모·비교·비율·기간을 제공.
- 일반화: 세그먼트 내부 차이와 예외를 확인.
- 운명: 천천히 변화하는 조건도 추적.
- 단일 관점: 여러 전문 관점·대안 원인을 검토.
- 비난: 개인 탓 이전에 시스템·조건을 조사.
- 긴급: 급한 결정에서 범위·불확실성·작은 검증을 확인.

첨부는 프랑스어 번역본이다. 현재 통계는 책의 과거 수치가 아닌 최신 근거로 확인한다.

## What Sticks의 4M (B39)
Motivations: 왜 고객이 선택하는가 → Message: 어떤 의미와 증거로 전달하는가 → Media: 어떤 접점에서 효과와 비용이 있는가 → Maximization: 무엇을 학습하고 개선하는가. 단순 노출 숫자만 최적화하지 말라.

## 측정 규칙 (에이전트 설계)
전환율=전환 고객/명시한 적격 분모. CAC=해당 범위 획득 비용/신규 획득 고객. ROAS=귀속 매출/광고 비용이며 이익·인과 ROI와 다르다. 증분 수익은 대조 조건과 비용 범위가 필요하다. GRR은 시작 반복 매출에서 이탈·축소를 빼고 시작 매출로 나눈 값, NRR은 확장도 더한 값이며 신규 고객 매출은 제외한다.

B36은 오차·인과·무작위화 장 제목만 확인 가능하다. 위의 구체적 측정·실험 지침은 손상된 책에서 추출한 것으로 표시하지 않는다.
