# 전략 충돌을 선택하는 규칙

| 충돌 | 선택·검증 조건 |
|---|---|
| 좁은 포지셔닝 vs 폭넓은 구매자 도달 | 메시지는 명확히 하고 매체 도달은 카테고리 구매자까지 확인. 니치의 수익성과 침투율을 비교. |
| 브랜드 의미 vs 실제 성능 정보 | 평가 가능한 상품이면 성능·비교·리뷰, 정체성 구매면 의미도 중요. 고객 조사로 영향 비중을 확인. |
| 브랜드 확장 경계 vs 포트폴리오 시너지 | 고객 인식 적합성·공유 자산·잠식·운영 복잡성을 조사하고 시험. |
| PR 우선 vs 판매 광고 | 신규 신뢰 형성에는 제삼자 증거, 수요 포착에는 광고 가설. 양쪽의 전환·증분 효과를 비교. |
| 놀라운 경험 vs 적은 노력 | 구매·체험에는 기억, 지원·문제 해결에는 노력 감소를 우선. 전체 여정 지표로 확인. |
| 대규모 침투 vs 핵심 계정 유지 | 소비재와 계약·구독 사업을 구분. 신규 고객 경제성과 유지 경제성을 함께 계산. |
| SPIN 탐색 vs Challenger 통찰 | 고객 이해가 부족하면 질문, 검증된 새 통찰이 있으면 제시. 압박·허구 손실을 쓰지 않음. |
| 기존 효율 vs 신사업 실험 | 평가 지표와 예산 경계를 분리하고 리더가 자원 충돌을 해결. |

이 표는 여러 소스를 결합한 에이전트 설계 판단이다. 단일 저자의 주장이나 검증된 보편 법칙이 아니다.
