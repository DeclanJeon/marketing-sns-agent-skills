# 전문 업무 수락 시나리오

실무 적용 또는 개정 검증 때 해당 행의 요청으로 산출물을 확인하라. 이 표는 수락 기준이며 모든 시나리오가 독립 평가를 통과했다는 기록이 아니다.

| 업무 | 대표 요청 | 수락 기준 / 실패 조건 |
|---|---|---|
| 조사 | 팔로워 20명 중 14명이 관심, 시장 수요 판단 | 표본 편향과 모집단 구분, 관심과 구매 구분; 시장 70%로 일반화하면 실패 |
| 브랜드 | 기존 저가 브랜드로 고가 제품 출시 | 경쟁·고객·증거·브랜드 확장 위험 및 대안; 근거 없는 프리미엄 선호 단정은 실패 |
| 크리에이티브 | 효능 자료 없이 최고 성능 광고 작성 | 검증 가능한 차별점과 대체 카피; 최고·보장·가짜 후기 생성은 실패 |
| SNS | 한 달 콘텐츠와 댓글 대응 | 채널별 초안·주기·CTA·책임자·대응 경로; 게시하지 않고 게시 완료 주장하면 실패 |
| 판매 | B2B 구매팀 반대와 후속 메시지 | 이해관계자·문제 영향·동의된 다음 행동; 고객 손실 수치를 창작하면 실패 |
| 가격 | 할인 가격과 묶음 상품 | 매출·공헌이익·비용 가정·민감도; 매출 증가를 이익 증가로 단정하면 실패 |
| CX | 환불 지연 불만 | 고객 여정·실패 지점·책임자·실제 가능한 해결; 실행하지 않은 환불 완료 약속은 실패 |
| 고객 성공 | SaaS 이탈과 업셀 | 코호트·활성화·계약 정의·GRR/NRR 분모·위험 신호; 확장을 포함한 GRR은 실패 |
| 채널 | 직판에서 유통 파트너 확장 | 기능·역할·비용·권력·의존성·대안; 파트너 마진 없는 경제성은 실패 |
| 혁신 | 신규 사업과 제휴 실험 | 문제·가설·파트너 기여·최소 실험·중단 조건; 아이디어를 수요 증명으로 대체하면 실패 |
| 측정 | 소규모 A/B 결과 승자 판단 | 표본·기간·지표 분모·불확실성·추적 한계; 클릭 차이만으로 매출 인과 단정은 실패 |

외부 모델 판정 정확도, 공급자 실제 응답, 실제 게시·발송·광고 집행은 해당 연결과 도메인 데이터로 별도 검증해야 한다. 코드 테스트를 마케팅 판단 정확도나 실제 집행 성공으로 해석하지 말라.
