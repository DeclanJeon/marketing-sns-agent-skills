# 요청 예시와 완료 조건

- “일본 골프투어 판매를 위한 고객 조사·오퍼·인스타그램 7개 원고를 만들어줘.” 가격과 휴일 조건은 사업 근거로 확인하고 완성 원고와 추적 계획을 제공하라.
- “구독 서비스의 이탈을 줄여줘.” 코호트·사용·고객 성과를 확인하고 건강도 가설, 실제 개입 대본, 측정 계획을 제공하라.
- “에이전트 팀에게 신제품 론칭을 맡겨줘.” 계약을 단계별로 나눠 의존성과 수락 기준을 지정하고 결과를 통합하라.
- “이 문장이 실제 자료와 일치하는지 true/false로 판단해줘. 공급자는 TypeSafe로.” judge 프로파일을 선택하고 근거 부족은 review로 남겨라.

완료 조건: 요청한 실제 산출물, 주장별 근거, 숫자 검산, 적용한 스킬, 다음 실행, 판단 오류·미설정 항목을 명시한다. 도구가 없으면 게시 성공이나 API 호출 성공을 주장하지 않는다.
