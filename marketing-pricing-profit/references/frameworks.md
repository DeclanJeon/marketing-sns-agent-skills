# 수익 모델 선택표 (B28)

| 모델 주제 | 검토할 수익 원천 |
|---|---|
| 고객 해결 | 고객 문제 이해와 통합 해결 |
| 가격·상품 피라미드 | 입문·핵심·상위 가치 구성 |
| 다중 구성 | 구성 요소마다 다른 가치 회수 |
| 연결 허브 | 공급·수요 연결 가치 |
| 시간 | 가치의 시간 차이 |
| 블록버스터 | 성공 상품 집중과 실패 비용 |
| 수익 반복 활용 | 하나의 자산을 여러 경로에 활용 |
| 기업가 실행 | 작은 조직의 기민한 책임 |
| 전문성 | 깊은 문제 해결 능력 |
| 설치 기반 | 기존 사용 기반의 후속 가치 |
| 사실상 표준 | 호환·확산·생태계 가치 |
| 브랜드 | 인식 자산의 고객 경제성 |
| 특화 상품 | 독특한 고객 가치 |
| 지역 우위 | 지역 밀도와 운영 효율 |
| 거래 규모 | 큰 거래의 비용·수익 구조 |
| 가치 사슬 위치 | 유리한 단계와 협상 구조 |
| 경기 순환 | 주기에 따른 가치·비용 변화 |
| 판매 후 | 유지·지원·확장 가치 |
| 새 제품 | 신규 가치의 수명과 방어 |
| 상대 점유율 | 경쟁 규모와 경제성 |
| 경험 곡선 | 축적 학습과 비용 변화 |
| 낮은 비용 사업 설계 | 전체 운영 구조의 비용 우위 |
| 디지털 | 복제·전달·연결의 비용 변화 |

각 모델에 고객 가치·권리·비용·진입 조건·실패 위험을 붙여라. 여러 모델을 조합할 수 있으며 특정 모델이 수익을 보장하지 않는다. 책의 교육용 대화를 실측 사업 증거와 구분한다.

## 가격 계산
단위 공헌이익=세금 기준을 통일한 실현 가격−상품 원가−거래 수수료−배송·반품·서비스의 변동비. 손익=공헌이익×판매 수량−기간 고정비. 할인 전후 필요 수량과 용량 한계를 함께 비교한다. 고정비와 이미 지출한 비용을 가격 결정의 유일한 기준으로 삼지 않는다. 제공 자료가 부족하면 수요·탄력성은 범위 가정으로만 입력한다.
