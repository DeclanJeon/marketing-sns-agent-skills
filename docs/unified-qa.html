## 2. 현금과 이익 계산

원가가 이미 지급됐어도 이익에서는 뺍니다. 현금 원장에서는 재고 원가 50만 원을 오늘 다시 지출하지 않습니다. 수수료·포장·교통·반품·세금·지원 비용은 미확인이므로 아래 금액은 알려진 항목만 계산한 조건부 값입니다.

| 경로/수량 | 알려진 항목 기준 공헌이익 | 오늘 이후 현금 흐름 | 3일 목표/가능 조건 |
|---|---:|---|---|
| 플랫폼 택배 1개 | 20,000−10,000−3,000=7,000원 | 발송 전 −3,000원 → 7일 뒤 +20,000원, 합계 +17,000원에서 미확인 비용 차감 | 첫 발송부터 3,000원 부족. 3일 내 판매대금 입금 0원 |
| 플랫폼 택배 50개 | 350,000원 | 발송 전 −150,000원 → 7일 뒤 +1,000,000원 | 정산 전 최대 150,000원 부족. 현금 0원으로 실행 불가 |
| 구매대금 먼저 실제 입금되는 직접 택배 1개 | 7,000원 | +20,000원 입금 확인 → 배송 −3,000원 → 17,000원에서 기타 의무 차감 | 해당 결제의 입금 시점·발송·환불 조건 확인 후만 가능 |
| 직접 수령 1개 | 배송비가 발생하지 않는 경우 10,000원에서 기타 비용 차감 | 수령 시 실제 +20,000원, 이동·포장 등 차감 | 수령 장소·배송비 면제 가능성·교통비 0원 가능 여부 미확인 |

직접 결제가 플랫폼 약관을 우회해도 된다는 뜻은 아닙니다. 기존 플랫폼 고객을 외부 결제로 유도하는 문안은 넣지 않았습니다. 독립적으로 이용 가능한 경로가 있다면 그 경로의 조건을 판매자가 확인해야 합니다. 제품 정보·이행 가능성·소비자 조건 확인 전 결제를 받지 않습니다. 고객 선입금 중 배송·환불 등에 필요한 돈은 자유 현금과 분리합니다. 준비금이 미정이라 재투자 가능한 금액은 확정할 수 없습니다.

추가 비용 0원이라는 가상 조건에서 직접 택배 q개를 이행하면 미래 현금 증가는 17,000q원, 공헌이익은 7,000q원입니다. 자유 현금 목표 T와 기타 예정 지출 U, 별도 준비금 R이 확정되면 필요 수량은 ceil((T+U+R)/17,000)입니다. 배송비를 U나 R에 중복 포함하지 않습니다. 이 식은 수요 예측이 아니며 q≤50, 2시간 내 처리 가능한 수량이어야 합니다.

현금 시나리오는 로컬 cash_ledger.py로 계산했습니다. 플랫폼 1개 시나리오는 기한 내 입금 0원·최대 부족 3,000원, 50개는 기한 내 입금 0원·최대 부족 150,000원입니다. 직접 선입금 1개는 알려진 순서만 보면 기한 내 +17,000원이나, 미확인 비용과 준비금 제외 전이라 실사용 가능액은 unknown입니다. 실제 판매·입금 기록은 없습니다.

(B) 소량 비품 구매를 검토하는 사업자는 일괄 수령 가능성이 있으나 소재·규격·납기 자료가 필요하고 의사결정이 3일보다 길 수 있습니다. 지금은 A 문의를 받는 원고를 쓰며 B 영업이나 발송은 실행하지 않습니다. 둘 다 수요 규모·접근성·가격 반응은 unknown입니다. 대안은 기존 베개 계속 사용, 다른 판매자의 베개, 구매 보류입니다. 차별 성능이 확인되지 않아 가격만으로 우월성을 주장하지 않습니다.

이 배정은 시간 상한 안에서의 작업 슬롯이며 완료 공수의 실측 추정이 아닙니다. 코드 수정·라이선스 결정·배포 허브 구축이 오래 걸리면 그 주의 출시 목표를 다음 주로 옮깁니다. 요청한 세 채널의 원고는 모두 유지하고 미제작 Shorts를 완료로 바꾸지 않습니다.

재사용 관계: 실제 동일 예제의 입력·결과가 공통 증거이고, X는 짧은 질문/캡처, 커뮤니티는 조건/반론, Shorts는 결과를 읽는 순서로 다시 구성합니다. Shorts 화면 크롭·자막·커버를 X/커뮤니티 그대로 복제하지 않습니다. 답변은 상대 질문에 맞춰 수정하며 무관한 대화에 반복 링크를 보내지 않습니다.

배포 후 체험용 허브에 필요한 내용: 기능 범위, 지원 OS/Python/의존성, 실제 실행 명령, 예제와 기대 출력, 중복·빈 행 정의, 라이선스, 입력 원본 보존 여부/주의점, 실제 문의 방법. 이번에는 페이지를 만들거나 URL을 발명하지 않았습니다.

UTM은 실제 URL이 생긴 뒤 사용: campaign=`csv_cleaner_seed`; source=`x`/`youtube`/선택한 커뮤니티명; medium=`organic_social`/`community`; content=`x01_r2`/`ys01_r2`/`cm01_r2`. 전체 링크는 현재 null. CTA를 다운로드로 바꾸면 revision 2로 올리고 링크·원고·자산 검토를 다시 합니다.
