# 실행과 수락 기준

예시 요청: 판매·전환 설계을 적용해 2인용 일본 골프투어 상품을 기획하고 판매를 늘릴 실행안을 만들어라. 공급 원가·휴일 추가금·취소 조건은 제공 자료만 사용한다.

수락 조건: 위 산출물을 실제 고객·상품 자료로 채워라. 숫자·정책이 없으면 명시적으로 확인 필요를 표시하라. “예약 30% 증가” 같은 결과를 보장하지 말라. 제안 가격과 승인 가격을 구분하라. SNS 초안을 요청받았다면 완성 원고를 제공하고, 게시까지 요청받았다면 승인 범위와 연결 상태를 확인해 실행 결과를 기록하라.

실패 예: 근거 없는 시장 규모; 가격과 추가금 누락; 템플릿만 반환; 고객 질문 없이 B2B 압박 대본 사용; 모델 확률만으로 외부 행동을 승인함.

## 단일 상품 수락 사례
요청: 베개 한 종류, 광고 예산 0원, 재고 보유. 일주일 안에 대금을 확보하는 판매안을 만들어라. 가격·배송비·정산일은 아직 미제공이다.
수락: 실제 특징 없이 수면·치료 효과를 창작하지 말라. 가상의 할인·이익·판매량을 확정하지 말라. 고객·실물 자료·판매문·사업자 제안·채널 비교를 준비하고 비용·정산 미확인에 표시하라. 유명인 선지출·무료 체험단을 예산 0원이라고 쓰거나 위탁 진열을 현금 확보로 세면 실패다.
