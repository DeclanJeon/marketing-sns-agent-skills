# 단일 상품·초기 현금 확보 판매 설계

이 문서는 최근 사용자 시나리오를 실행 절차로 구성한 운영 설계다. 책에서 직접 추출한 규칙, 시장 수요의 증명, 판매 성공 보장이 아니다.

## 입력과 우선 목표
상품 수, 재고·생산·입고 상태, 실제 특징·적합/부적합 고객, 가격, 비용, 보유 현금, 자금 투입 상한, 대금 회수 기한, 배송·환불·지원 가능 범위를 확인하라. 한 상품이라고 해도 재고 하나인지 한 종류인지 구분하라. 모르면 준비 작업을 계속하고 수익성·집행 가능성만 미확인으로 남겨라. 조회·신뢰·문의·주문·결제·실제 입금·재구매를 분리하라. 목표가 현금 회수이면 광고 노출량을 성공 기준으로 대체하지 말라.

## 후보 선택
| 후보 | 구매 연결 | 현금·운영 확인 |
|---|---|---|
| 소비자 직접 판매 | 실물 설명→적합성 확인→주문 | 결제 경로 정산일·배송 선지출·반품 |
| 소량 사업자 매입 | 고객 용도 확인→견적→결제→납품 | 매입/위탁/외상 구분·단가·납기·결제일 |
| 성과형 제휴 | 파트너 고객 적합성→추천→구매 | 샘플·배송도 비용, 수수료 기준·취소 차감·정산일 |
| 공동구매 | 관심 확인→수량 조건→주문 | 신청을 확정 매출로 계산하지 말고 공급 수량·납기 확인 |
| 체험·리뷰 | 실제 사용→근거→구매 경로 | 무료 제공 비용·후기 편향·광고 관계 표시, 긍정 후기 요구 금지 |
| 매장 위탁 | 진열→소비자 판매→점포 정산 | 상품을 맡긴 것을 판매나 입금으로 기록하지 말라 |
| 예약 판매 | 확정 가능한 공급→일정·조건 안내→주문 | 납품·환불 의무와 필요한 자금 확보, 자유롭게 쓸 돈과 분리 |

현재 접근 가능한 고객, 구매 경로, 선지출, 단위 공헌이익, 실제 입금일, 이행 가능성으로 2~3개 후보를 비교하라. 고객 접근·수요 근거가 없는 후보는 실험으로 표시하라. 기한 내 현금 부족·음수 공헌이익·불가능한 납기를 표시하고 무조건 직접 판매가 빠르거나 B2B가 잘 팔린다고 단정하지 말라.

## 오퍼와 접촉
확인된 특징으로 한 고객 상황을 설명하고 가격·포함 사항·배송·교환 조건·다음 행동을 완성하라. 단일 상품의 수량별 구매·도입 지원·진실한 서비스 차등은 가능하나 없는 액세서리·상품·효능·원가를 만들어 묶지 말라. 제한 수량·기한은 실제 재고·조건과 일치해야 한다. 유명인이나 체험단은 구매 연결·비용·정산이 있어야 판매 후보로 평가한다.

상담 질문은 취향·현재 해결책·불편·구매 조건을 확인하고 맞지 않는 고객에게는 적합하지 않음을 설명하라. 방문·메시지 초안은 허용된 채널·대상·개인정보 범위로 준비하고 실제 발송은 기존 승인 범위와 연결 도구가 있어야 한다. 반복 접촉은 거절·수신 중단·해결 상태에 맞춰 중단하라.

## 실험·기록·후속
최초 유료 주문 목표는 사용자의 기한·재고·처리량에 맞춰 실험 목표로 정하라. 10건 등 예시 숫자를 수요 예측이나 성공 보장으로 쓰지 말라. 기간·담당자·대상 수·선지출 상한·정산일·중단 조건을 붙이고 판매문, 사업자 제안문, 후속 답변을 실제 자료로 완성하라.

리드는 신규→적합성 확인→제안→주문→결제→입금→배송→완료/취소로 추적하라. 각 기록에 주문 ID·채널·다음 행동·약속일·정산 예정/실제일을 붙여라. 무응답을 거절이나 매출로 기록하지 말라. 거절 이유는 가격·적합성·신뢰·배송·조건·시점 등 실제 응답으로 기록하고 단서를 보고 한 변수씩 수정하라. 후기·재구매·소개는 이행 후 실제 고객에게 요청하고 사실을 보존하라.

수락 기준: 준비한 산출물, 공헌이익, 기한별 현금, 미확인 근거, 다음 행동을 반환하라. 판매되지 않은 위탁 재고·신청·플랫폼 미정산 매출을 보유 현금으로 합산하면 실패다.
